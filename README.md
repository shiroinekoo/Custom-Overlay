# About

<img src="https://raw.githubusercontent.com/shiroinekoo/Tako-Overlay/main/asset/preview overlay/mikasa-chibi-overlay.png" width="100%" alt="Mikasa Overlay Preview">

Custom Alert Overlay untuk Tako / Saweria dengan tema **Mikasa Ackerman (Attack on Titan)**. Dirancang khusus agar pas di layar OBS Studio dan mudah dibaca oleh penonton.

---

## ✨ Fitur Utama
* **AOT Typography:** Menggunakan Font bertema Attack on Titan (`Tschichold-Bold`).
* **Custom Color Scheme:** Skema warna disesuaikan dengan atribut Mikasa (Syal Merah & Jaket Coklat).
* **OBS Ready:** Ukuran font dan kontras shadow sudah dioptimalkan untuk resolusi stream 1080p.

---

## 🚀 Cara Pemasangan di Tako / Saweria

1. Salin seluruh isi kode dari file [`index.html`](./index.html) di repositori ini.
2. Buka dashboard **Tako / Saweria** kamu.
3. Masuk ke bagian **Overlay / Custom HTML CSS**.
4. Tempelkan kode ke dalam editor lalu simpan.
5. Salin URL Widget dari Tako, lalu tambahkan ke OBS Studio sebagai **Browser Source**.
